# MOTION SYSTEM

## Motion principles

- Motion must feel athletic, disciplined and premium.
- Each animation should guide attention or communicate state.
- Motion should vary by context rather than reusing the same reveal everywhere.
- Reduced-motion users must still receive clear state feedback.

## Token direction

- Duration short: 140ms
- Duration base: 220ms
- Duration medium: 360ms
- Duration long: 560ms
- Easing out: cubic-bezier(0.22, 1, 0.36, 1)
- Easing in-out: cubic-bezier(0.65, 0, 0.35, 1)

## Planned choreography

- Header: quick entrance with solidifying backdrop on scroll.
- Hero: image mask reveal, text sequence and restrained CTA rise.
- Section transitions: alternating directional reveals, scale restraint and edge masking.
- Cards: crop shift, underline sweep and focus parity.
- Commerce: filter transitions, gallery crossfade and cart drawer motion.
- Forms: field-state feedback with accessible validation messaging.

## Reduced motion

- Remove parallax and large scroll-based transforms.
- Shorten sequencing.
- Preserve focus and state cues.
- Keep layouts and content stable.
