# Home of Fitness

Premium fitness brand website for memberships, classes, trainers, facilities and fitness commerce.

## Tech stack

- React
- TypeScript
- Vite
- Framer Motion
- React Router

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
- `npm run format`
- `npm run format:check`

## Notes

- British English is used across visible copy and documentation.
- Currency is Nigerian naira.
- Asset provenance must be confirmed before final production release.
